08 / PCB DEFECT DETECTION

PCB Defect Detection

Python TensorFlow Keras OpenCV FastAPI PostgreSQL React Tailwind

An end-to-end PCB defect inspection system — upload or capture a PCB image and the app aligns the board, classifies defects with a trained CNN (98.2% accuracy), explains the decision with a Grad-CAM heatmap, applies repair-vs-scrap business logic, and surfaces yield analytics.

  • Classifies 6 defect classes (missing_hole, mouse_bite, open_circuit, short, spur, spurious_copper) with a compact strided-conv CNN.
  • PCB validation gate rejects non-PCB inputs (hands, blank photos) before inference, with ORB-based board alignment.
  • Grad-CAM heatmaps explain each prediction, and repair-cost business logic decides OK / REPAIRABLE / SCRAP.
  • Batch inspection via ZIP upload, every inspection stored in PostgreSQL (Alembic-managed), and a yield analytics dashboard.
